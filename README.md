Descripción

Este repositorio reúne el desarrollo documentado del TSP de Computación II(324).

Los programas se elaboran en C++, con comentarios, pruebas y explicaciones de las estructuras de datos utilizadas.

Objetivos

Objetivo 1: Elaborar un TAD (Tipo Abstracto de Datos) para representar un dato particular.

Objetivo 2: Resolver problemas de tipo algorítmico aplicando el TAD Lista Enlazada

Objetivo 3: Resolver problemas de tipo algorítmico aplicando el TAD Pila y/o el TAD Cola

Objetivo 4:Resolver problemas de tipo algorítmico aplicando el TAD Árbol

Organización

Cada objetivo tendrá su propia carpeta con los programas y la documentación correspondiente.
