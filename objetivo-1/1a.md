Objetivo 1 — TAD CadenaBinaria

Descripción

Representa una cadena formada por 8 dígitos binarios, donde cada dígito puede ser 0 o 1.

Datos

Cadena de 8 bits.

Cada posición almacena un 0 o un 1.

Operaciones

Negar(): cambia cada bit de 0 a 1 y de 1 a 0.

Gray(): genera una nueva cadena aplicando la operación XOR entre cada bit y el bit anterior, comenzando desde el segundo bit.

Longitud(): devuelve la cantidad de bits de la cadena, que es 8.

InspeccionarBit(posición): permite consultar el bit que se encuentra en una posición determinada.

Sumar(otraCadena): suma dos cadenas binarias de igual longitud sin generar acarreos.

Representación general

CadenaBinaria → Datos de 8 bits + Operaciones

El TAD permite trabajar con las cadenas binarias mediante operaciones definidas, sin tener que manejar directamente todos los detalles de su implementación.
